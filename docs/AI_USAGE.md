# AI 使用说明与研究过程

## 实际分工

项目发起者提出电机数学建模、MATLAB求解、完整论文、问题审查和修订的需求，并决定公开展示。AI代理在本地环境中完成了大量模型构造、程序编写与调试、MATLAB运行、结果检查、图表制作、论文排版和仓库整理。

当前记录不能证明项目发起者已经独立推导全部模型或独立复现全部代码。因此，本项目应表述为“AI辅助完成的建模案例”；不应表述为“全部独立开发”或“已完成真实电机验证”。后续亲自完成的复现、修改和解释，可以按实际情况加入提交记录。

## 使用方式

AI用于明确数学定义、生成和修改MATLAB代码、读取求解输出、检查约束、撰写和排版。运行时使用了MATLAB优化、数据分析、图表以及文档相关技能说明；技能文件和第三方工具本身不随仓库复制。

所有数值来自实际执行MATLAB获得的本题模拟计算。训练误差很小不等于实机预测准确；有限时间整数可行解不等于连续问题的精确最优；有限场景回放与单调性证明各有不同作用。
